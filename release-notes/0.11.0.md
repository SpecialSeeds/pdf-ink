## Key features
- Dynamic pen thickness: a new setting (off by default). Pen strokes written with a pencil get thinner as you press lighter and thicker as you press harder. Ink you've already written keeps its shape.
- Export original pages only: when a PDF has inserted pages, the export dialog offers "Original pages only", which exports the PDF's own pages with their ink and leaves the inserted pages out. It is saved beside the usual export as `<name> (annotated) (original pages).pdf`.

## Bugs fixed
- None.

## QoL improvements
- Pressure is smoothed while you write, so stroke width changes gradually instead of wobbling.
- Choosing "Original pages only" doesn't change the theme the export dialog preselects next time.
