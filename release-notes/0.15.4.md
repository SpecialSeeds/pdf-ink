## Bugs fixed
- The stroke eraser no longer erases a shape you aren't touching. It used to test a shape against its whole bounding box, so a diagonal line could be erased from anywhere in the square it spans. Now only the drawn lines count, plus arrowheads and the inside of filled shapes.
- The stroke eraser's reach is now measured in screen pixels, so it feels the same at any zoom. It used to grow as you zoomed in. If you set a custom reach, it's now read as pixels, so it covers a smaller area than before.

## QoL improvements
- The stroke eraser now shows a circle at its real reach, like the sized eraser does.
