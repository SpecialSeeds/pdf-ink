## Key features
- Choose the export quality, from Super low to Ultra high, with a slider in the export dialog. The file size updates as you move it, and it's the exact size of the file you'll get. Lower levels simplify ink outlines and shrink pictures; every level stays sharp vector ink, never an image of the page. Your choice is remembered, and you can also set it in Settings → Export.

## QoL improvements
- Exporting from the command palette only offers "Original pages only" when the PDF actually has inserted pages.
- The export now defaults to High quality: visually identical to before, with pictures capped at 300 dpi, so files can come out smaller. Pick Ultra high for the exact previous output.
