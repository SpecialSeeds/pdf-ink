## Key features
- New board is now a temporary infinite canvas, like a whiteboard. It grows in every direction as you write or pan near an edge, and it's thrown away when you close its tab (with a 10-second Reopen) or quit Obsidian. Keep what matters by sending it to a notebook: select some ink and tap the notebook button, or use "Send board to a notebook" for the whole board. Name a new notebook on the spot or pick an existing one, and the ink lands on a new last page with its pictures copied beside it. Boards you already have, and OneNote imports, stay as saved notebooks and work as before.
- Clear the board in one tap, like a boogie board: the trash button on a temporary board wipes everything, and one undo brings it all back.
- A Graph shape draws 5 mm graph paper. The squares always stay 5 mm, so making it bigger adds squares instead of stretching them.
- Turn an inserted page between portrait and landscape from the page menu.
- Insert several pictures at once, from the picker, a paste or a drop. They're laid out in a grid and selected together, and one undo removes them all.

## Bugs fixed
- Arrowheads on arrows and axes are now added on to the end of the line, so the point is the very tip, with no line poking out past it.

## QoL improvements
- Lock scrolling both ways, so the page stays still while you write. Page buttons and zoom still work.
- The tool palette can sit along the bottom of the view (Settings → Tool palette position).
- The eraser's options open from where the colours are for the other tools, instead of from a separate arrow beside the eraser.
- The whole-stroke eraser's reach now goes from 2 to 120 px.
- Boards can no longer take extra pages from any menu or button; only their ruling changes.

**Note:** this version saves files in a new format (version 7) so the graph shape can't be lost. Update the plugin on every device before using it: older versions refuse to open a file this one has saved.
