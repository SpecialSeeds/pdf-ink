## Key features
- Link a PDF or notebook to other files by typing a wikilink into a text box: `[[Note]]`, `[[Worksheet 3.pdf#page=2]]` or `[[Note#Heading|alias]]`. The box shows the alias or the file's name, underlined in the link colour, and the brackets come back while you edit it.
- Tap a link with a finger, `Ctrl`/`Cmd`+click it, or click it in reading mode to open the target. Hold `Ctrl`/`Cmd` over it for a page preview.
- Links show in the graph view, from the PDF or notebook to the file it links to (turn on Attachments in the graph's filters to see PDFs). A link to a file that doesn't exist yet shows as an unresolved link.
- Renaming a linked file updates the link text in your boxes when Obsidian's "Automatically update internal links" is on, even in files that aren't open.
- Exported PDFs keep the links: drawn without brackets, and clickable through an `obsidian://` link that opens the target in your vault.

## Bugs fixed
- None in this release.

## QoL improvements
- The eraser's two modes, whole stroke and sized, are now buttons in the palette where the colours sit for the other tools, instead of behind an arrow. The size button sets the eraser's reach or radius.
- A new setting, "Show ink links in graph and backlinks", turns the link index off. Turning it off removes every link the plugin added.

**Note:** the Backlinks pane doesn't list PDFs or notebooks, because Obsidian only searches markdown and a few built-in file types there. Use the graph to see these links.
